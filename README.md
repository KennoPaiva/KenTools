# KenTools v2.0

> Automatize. Otimize. Resolva.

Ferramenta de suporte técnico com interface gráfica criada para
técnicos de campo que precisam agilizar o atendimento no dia a dia.

---

## Como usar

1. Baixe o `KenTools.exe`
2. Clique com o botão direito → **Executar como Administrador**
3. Pronto — sem instalação, sem dependências

---

## Funcionalidades

| Aba | O que faz |
|-----|-----------|
| Instalar Programas | Instala os principais softwares via Winget com um clique |
| Remover Bloatware | Remove apps desnecessários do Windows |
| Tweaks + Serviços | Aplica otimizações de performance e privacidade |
| Sistema | Informações completas de hardware |
| Microsoft | Baixa e instala o Office |
| Ajustes | Configurações rápidas do Windows |
| Rede | Diagnósticos e configuração de DNS |
| Usuários | Gerencia usuários locais |
| Rotina de Atendimento | Checklist completo com relatório automático em .txt |

---

## Requisitos

- Windows 10 / 11
- Executar como Administrador
